# Illustration System v0.1

## 目的

Kid Story 的正式成品不是純文字，而是「圖像化睡前故事書」。插畫系統的目標是：讓 3–6 歲孩子容易進入情境，同時讓角色在不同頁面之間保持一致，並把 AI 感降到最低。

## 產品原則

1. 正式成品必須有圖；純文字只作為內部草稿與家長預覽。
2. 圖像要先服務故事理解，再服務美感。
3. 不追求高細節 3D、電影感或過度光影。
4. 優先使用手繪紙感、色鉛筆、蠟筆、水彩邊緣等質地。
5. 背景保持簡潔，讓孩子一眼知道「主角正在做什麼」。
6. 一頁只表達一個主要動作或情緒。
7. 不直接複製既有卡通／電影角色；若孩子喜歡某作品，只抽取高階敘事元素，例如勇敢、任務、團隊、冒險。

## 視覺語言

- 年齡感：3–6 歲幼兒繪本
- 整體：溫暖、輕冒險、低飽和、乾淨、留白
- 媒材感：色鉛筆 + 蠟筆 + 淡水彩紙感
- 線條：自然手繪，不追求完美向量線
- 光影：柔和自然，不做戲劇化輪廓光
- 場景：生活化、容易辨識
- 表情：清楚但不誇張，不做大型 3D 卡通眼

## Character Lock

每一本書在生圖前必須建立 Character Card。以下欄位一旦確認後，全書鎖定：

- 大致年齡
- 髮型與髮色
- 臉部輪廓（僅風格化描述）
- 主服裝
- 鞋子
- 主色系
- 招牌動作
- 個性表情範圍
- 是否有固定物件／玩偶

同一本書不得自行改變：

- 髮長
- 衣服款式與主要顏色
- 鞋子
- 臉部基本比例
- 年齡感
- 招牌動作特徵

## Photo-free Mode（預設）

第一階段預設不要求孩子照片。

家長只需選擇：

- 髮長：短／中／長
- 髮型：直髮／微捲／綁髮等
- 髮色
- 膚色範圍
- 常穿顏色
- 是否戴眼鏡
- 其他明顯但不敏感的外觀特徵

成品目標是「讓孩子覺得像自己」，不是寫實肖像。

## Photo-assisted Mode（未來高階版）

若未來提供照片輔助版本，需：

- 家長主動選擇
- 明確說明照片用途、保存期間與刪除方式
- 不把照片或可辨識影像提交至公開 GitHub
- 仍採插畫化，不製作寫實人像

## Page Composition

建議正式版：封面 + 14–16 個內頁畫面。

每頁原則：

- 文字 1–4 句
- 主角 1 個主要動作
- 最多 1 個故事焦點物件
- 留足文字區域，不把關鍵角色壓在版心或裁切邊
- 連續頁面需有視覺節奏：近景 / 中景 / 全景交替

## Story-to-Image Pipeline

1. Intake 完成
2. Story Plan 確認
3. Draft 確認
4. Page Script 拆頁
5. Character Card 鎖定
6. 先生成 Character Reference Sheet
7. 先測 3 個關鍵場景：日常、動作、情緒
8. 一致性通過後再做全書
9. 視覺 QA
10. 排版成電子繪本

## 視覺 QA

每頁檢查：

- 角色是否仍像同一個孩子
- 年齡感是否一致
- 衣著是否一致
- 左右手／肢體是否自然
- 畫面是否真的符合該頁文字
- 是否多出不必要角色或物件
- 是否過度華麗搶走故事焦點
- 是否出現文字亂碼
- 是否有明顯 AI 常見錯誤

全書檢查：

- 主角辨識度是否穩定
- 三個重要場景是否看得懂
- 口訣頁是否在畫面上強調腳、眼睛與停下動作
- 封面是否能一眼知道是「這個孩子的故事」

## v0.1 驗證指標

第一輪 Founder Beta 特別觀察：

- 孩子是否會主動指圖
- 是否因圖片理解故事情境
- 哪一頁停留最久
- 哪一頁沒有興趣
- 是否能從圖片說出正在發生什麼
- 第二次閱讀時是否能預測下一個動作或口訣
