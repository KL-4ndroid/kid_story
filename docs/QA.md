# Story QA v0.1

每本故事在交付前必須通過以下檢查。

## A. 個人化

- [ ] 主角稱呼正確
- [ ] 年齡感正確
- [ ] 至少 2 個細節讓家長感覺「這是我家孩子」
- [ ] 沒有把問卷所有資訊硬塞進故事
- [ ] 沒有出現未提供、又可能造成錯誤理解的家庭設定

## B. 故事性

- [ ] 開頭不是直接說教
- [ ] 有明確事件發生
- [ ] 陪伴角色有功能，不只是裝飾
- [ ] 主角有主動選擇
- [ ] 有一個小小的轉變
- [ ] 結尾降速，適合睡前

## C. 語言

- [ ] 適合 3–6 歲理解
- [ ] 句子不過長
- [ ] 抽象詞有轉成具體畫面
- [ ] 沒有成人式長篇大道理
- [ ] 沒有大量華麗形容詞與 AI 式堆疊
- [ ] 念起來自然

## D. 情緒與教養界線

- [ ] 沒有乖／不乖標籤
- [ ] 沒有羞辱
- [ ] 沒有恐嚇
- [ ] 沒有條件式愛
- [ ] 沒有把哭／怕／生氣寫成錯誤
- [ ] 沒有把家長的需求假裝成孩子自己的想法
- [ ] 沒有用故事逼孩子答應某件事

## E. 效果承諾

- [ ] 結尾不是「從此以後再也不……」
- [ ] 沒有暗示故事可取代專業協助
- [ ] 沒有醫療或心理診斷
- [ ] 小行動符合孩子目前能力

## F. 安全

- [ ] Safety Gate = PASS
- [ ] 禁忌元素沒有出現
- [ ] 沒有新增不必要的危險內容
- [ ] 沒有真實可識別個資出現在內部測試紀錄

## G. AI 感檢查

優先重寫以下跡象：

- 每段都像金句
- 過度使用「原來……」「這一刻……」「從那天起……」
- 角色一直精準說出心理學答案
- 每一幕都過度唯美
- 結尾把主題總結成一段大道理
- 語句太整齊、太工整、太像模板

## QA 分數

每項 0–2 分：

- 個人化
- 故事性
- 年齡適配
- 自然口語
- 情緒尊重
- 低說教感
- 低 AI 感
- 睡前適配

滿分 16。

交付門檻：
- 總分 >= 13
- 「情緒尊重」「低說教感」「安全」不得低於 2

## 人工朗讀測試

正式交付前，創辦人至少快速朗讀一次。

若念起來卡、太長、像文章，不應交付。

真正的測試不是「看起來寫得好」，而是「晚上念給孩子聽順不順」。
