# Safety & Scope v0.1

## 產品定位界線

本產品是親子共讀故事工具，不是：
- 醫療服務
- 心理治療
- 發展評估
- 精神疾病診斷
- 危機處理
- 行為矯正療程

故事不能被描述成「治療孩子」「改善症狀」「矯正行為」或保證成效。

## Safety Gate 分類

### PASS｜可處理

一般生活與家庭情境，例如：
- 睡前拖延
- 怕黑
- 上學緊張
- 刷牙洗澡抗拒
- 手足適應
- 一般生氣、挫折、等待
- 搬家、旅行、看牙醫等日常適應

### REVIEW｜需要創辦人判斷

- 長期、劇烈、已明顯影響日常功能的恐懼
- 長期失眠或明顯睡眠異常
- 持續攻擊行為
- 疑似霸凌但資訊不足
- 家長描述可能涉及發展、情緒或感官問題

此類不直接自動生成，先確認是否只是一般情境，必要時建議尋求專業協助。

### OUT_OF_SCOPE｜停止故事流程

若家長描述包含：
- 自傷或自殺意念／行為
- 虐待、性侵、重大創傷
- 嚴重暴力或危及他人安全
- 明顯精神症狀或急性危機
- 需要醫療診斷／用藥建議
- 希望利用故事隱瞞、操控、威嚇孩子

則不得把故事當成主要解法。

## OUT_OF_SCOPE 回應原則

- 明確說明這超過本故事產品適合處理的範圍。
- 鼓勵家長尋求合適的兒科、心理、教育或其他專業支持。
- 若涉及即時危險，提醒優先確保孩子安全並尋求當地緊急協助。
- 不做診斷。
- 不把責任推給孩子或家長。

## 禁止的故事手法

任何主題都禁止：
- 恐嚇：「不睡覺怪獸就來抓你」
- 羞辱：「大家都會，只有你不會」
- 條件式愛：「乖乖睡媽媽才愛你」
- 拋棄威脅：「再哭爸爸就不要你」
- 強迫道歉／擁抱作為唯一正確結局
- 把哭、生氣、害怕寫成錯誤或壞行為
- 用疼痛、事故或死亡嚇孩子服從
- 成人化心理診斷語言
- 將真實家庭成員寫成反派以操控孩子

## 隱私規則

### 不需要蒐集

- 孩子完整姓名
- 精確生日
- 學校全名
- 地址
- 身分證件
- 家長工作地點
- 任何與故事無關的聯絡或定位資訊

### Repo 規則

此 repository 為公開 repo，因此：
- 不提交真實兒童姓名
- 不提交孩子照片
- 不提交未去識別化家長問卷
- 不提交可反推出家庭身分的案例
- 範例一律使用虛構人物

### 測試回饋

GitHub Issue 只記錄：
- 流程問題
- 使用感受
- 功能建議
- 匿名化故事問題

不得貼真實孩子敏感資料。

## 圖像安全

初版不要求孩子照片。角色可依文字描述建立，例如：
- 4 歲
- 黑色短髮
- 黃色睡衣
- 喜歡恐龍

這樣足以產生「像是他的故事」，又避免不必要的兒童影像資料處理。
