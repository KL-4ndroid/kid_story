# Product Options Architecture v0.3

## 目的

Kid Story 不把「客製」理解成只有改名字。真正的個人化應該讓家長選擇：孩子是否直接成為主角、角色要多像孩子本人、是否願意提供照片、故事中使用什麼稱呼，以及整本繪本使用哪一種固定畫風。

這些選項必須簡單、可選、可理解，不能讓家長在正式進入故事前像填複雜表單。

## 1. 主角模式

### A｜孩子本人作為主角

故事中的主角就是孩子本人。

適合：
- 希望孩子有高度代入感
- 希望成品有收藏價值
- 希望孩子一眼知道「這是在說我」

可搭配 Photo-free 或 Photo-assisted。

### B｜以孩子為靈感的原創角色

角色的個性、喜好、情境來自孩子，但外型與名字可以保留童話化距離。

適合：
- 希望保留一點隱私
- 喜歡較童話化的故事
- 不希望故事太像直接在教育孩子本人

### C｜孩子不直接出現在故事中

由原創小孩、動物或象徵角色承載這次情境。

適合：
- 不希望孩子成為故事主角
- 對肖像與個資較保守
- 希望透過第三人稱安全距離理解議題

## 2. 外型相似度

當主角模式為 A 或 B 時，家長可選：

### L1｜感覺像就好

只保留年齡感、髮型、色系、個性與招牌動作。

### L2｜希望看得出來是他

加入更具體的臉型、髮型、穿著與明顯特徵。Photo-assisted 時以此為預設目標。

### L3｜不希望太像本人

即使提供照片，也只抽取高階視覺特徵，保留明顯插畫化與童話距離。

Kid Story 不承諾寫實肖像複製。

## 3. 照片模式

### P0｜不提供照片

完全可完成正式商品。

家長只需提供：
- 髮長／髮型
- 髮色
- 膚色範圍
- 是否戴眼鏡
- 常穿顏色
- 一兩個明顯外觀特徵

### P1｜提供 1 張大頭照（選填）

用途：協助插畫角色更接近孩子。

原則：
- 仍為繪本插畫，不轉成寫實肖像
- 不要求正裝或證件照
- 清楚、近期、正面或 45 度即可

### P2｜提供 2–3 張參考照（未來 Premium）

可包含：
- 正面大頭照
- 側面／45 度
- 日常穿著參考

目的：提高角色一致性與辨識度，不追求照片級複製。

## 4. 稱呼模式

家長可選：
- 本名
- 暱稱
- 自訂故事名
- 不使用孩子真實稱呼

## 5. 官方繪圖風格

詳細定義見 `docs/STYLE_PRESETS.md`。

### S1｜粗線平圖

清楚、活潑、童趣。粗線條、大色塊、細節最少，適合動作理解與任務感較強的故事。

### S2｜拼貼繪本

手作、紙感、有作品感。以剪紙、拼貼、不規則手繪線與低飽和色塊建立畫面。

### S3｜粉彩童話

柔和、安靜、有童話感。以乾粉彩／粉蠟筆、淡水彩暈染與留白為主，適合睡前閱讀。

正式商品不使用無限制自由畫風。顧客從 S1 / S2 / S3 中選擇，方便建立一致的 Style Lock 與穩定 QA。

## 6. 推薦商品組合

### Standard｜輕客製繪本
- 主角 A 或 B
- P0 不提供照片
- L1 或 L3
- S1 / S2 / S3 任選
- 適合低門檻、快速交付

### Portrait｜肖像感客製繪本
- 主角 A
- P1 提供 1 張大頭照
- L2 希望看得出來是孩子
- S1 / S2 / S3 任選
- 預期成為多數家長最有感的版本

### Story Distance｜象徵角色版
- 主角 B 或 C
- P0 為主
- 用角色承載情境
- S1 / S2 / S3 任選
- 適合希望有心理距離或重視隱私的家庭

## 7. 前置設定問答

前四題應在正式故事 Intake 的最前面或視覺階段最前面完成，並用聊天方式一次最多問 1–2 題。

### Q0-1｜這次故事裡，你希望誰是主角？

- 孩子本人
- 以孩子為靈感的原創角色
- 孩子不直接出現在故事裡

### Q0-2｜如果孩子／孩子靈感角色會出現，你希望外型多像本人？

- 感覺像就好
- 希望看得出來是他
- 不希望太像本人

### Q0-3｜是否願意提供孩子照片作為插畫參考？

- 不提供
- 提供 1 張大頭照
- 2–3 張參考照（未來 Premium）

必須明示：選擇不提供照片，不影響完成正式繪本。

### Q0-4｜故事中怎麼稱呼孩子？

- 本名
- 暱稱
- 自訂故事名

### Style Choice｜你喜歡哪一種畫風？

需搭配三張固定風格預覽圖：

- S1｜粗線平圖
- S2｜拼貼繪本
- S3｜粉彩童話

Style Choice 不一定要在第一分鐘詢問；較推薦在 Story Plan 與 Character Card 已形成後、正式大量生圖前選擇，避免家長一開始資訊負擔太高。

## 8. 隱私與照片規則

只要使用照片，產品必須在上傳前清楚說明：

- 照片用途只限於該次插畫角色建立與品質檢查
- 不放入公開 GitHub、公開案例或行銷素材
- 未經家長另行同意不得公開
- 必須有明確的保存期間與刪除政策
- 應採最少資料原則，不要求學校、地址、完整生日等無關資料

MVP 階段在正式對外收照片前，必須先完成可執行的照片保存與刪除機制。

## 9. 產品體驗原則

1. 不提供照片不是低階或殘缺版本。
2. 提供照片的價值是增加「這像我的孩子」的辨識感，而不是做寫實肖像。
3. 家長永遠可以在不提供真名與照片的情況下完成一本書。
4. 主角模式是故事選擇，不應暗示哪一種比較正確。
5. Style Preset 是視覺選擇，不改變故事內容與 Character Lock。
6. 顧客選定畫風後，全書使用同一 Style Lock。
7. 每一本正式商品仍包含兩個成果：
   - 給現在孩子看的圖像故事
   - 留給未來孩子看的 Growth Record 成長紀錄

## 10. Founder Beta #1 建議設定

第一位創辦人體驗目前設定：

- 主角模式：A｜孩子本人
- 相似度：L2｜希望看得出來是她
- 照片模式：P1｜提供 1 張大頭照
- 稱呼：使用家長指定稱呼
- 畫風：由 S1 / S2 / S3 中實際比較後選定

測試核心：
- 孩子是否因「角色像自己」而提高注視、指圖、重讀與代入感
- 三種畫風哪一種最低 AI 感
- 三種畫風哪一種最適合 4 歲孩子理解畫面
- 三種畫風哪一種最有收藏價值
